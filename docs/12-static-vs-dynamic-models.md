# مقایسه مدل‌های ایستایی و پویا

## مقدمه

در UML مدل‌ها به دو دسته کلی تقسیم می‌شوند:

- مدل‌های ایستایی (Static Models)
- مدل‌های پویا (Dynamic Models)

---

## مدل‌های ایستایی

مدل‌های ایستایی ساختار سیستم را نشان می‌دهند.

ویژگی‌ها:
- نمایش کلاس‌ها
- نمایش ویژگی‌ها
- نمایش روابط بین کلاس‌ها
- بدون نمایش زمان

نمونه نمودارها:
- Class Diagram
- Object Diagram
- Package Diagram

مزایا:
- طراحی ساختار سیستم
- ساده بودن تحلیل

---

## مدل‌های پویا

مدل‌های پویا رفتار سیستم را در طول زمان نشان می‌دهند.

ویژگی‌ها:
- نمایش توالی عملیات
- نمایش تعامل کاربران
- نمایش جریان اجرای سیستم

نمونه نمودارها:
- Use Case Diagram
- Activity Diagram
- Sequence Diagram
- State Diagram

مزایا:
- تحلیل رفتار سیستم
- درک بهتر فرآیندها

---

## مقایسه

| مدل ایستایی | مدل پویا |
|-------------|----------|
| نمایش ساختار | نمایش رفتار |
| بدون زمان | وابسته به زمان |
| کلاس‌ها و روابط | فعالیت‌ها و تعاملات |
| طراحی معماری | طراحی فرآیندها |

---

## نتیجه

مدل‌های ایستایی و پویا مکمل یکدیگر هستند. مدل‌های ایستایی ساختار نرم‌افزار را مشخص می‌کنند و مدل‌های پویا نحوه عملکرد و تعامل اجزای سیستم را نشان می‌دهند.
