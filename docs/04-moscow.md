# اولویت‌بندی قابلیت‌ها (MoSCoW)

## Must Have (ضروری)
- ثبت‌نام و ورود کاربران
- ثبت درخواست تعمیر موبایل
- جستجو و انتخاب تعمیرکار
- نمایش هزینه تقریبی تعمیر
- ثبت وضعیت مراحل تعمیر
- اطلاع‌رسانی به مشتری
- ثبت نظر و امتیاز برای تعمیرکار

## Should Have (مهم)
- گفتگوی آنلاین مشتری و تعمیرکار
- مشاهده سوابق تعمیرات
- مقایسه تعمیرکاران
- امکان پرداخت آنلاین

## Could Have (بهتر است باشد)
- پیشنهاد هوشمند بهترین تعمیرکار
- تخفیف و کد هدیه
- نمایش نزدیک‌ترین تعمیرکار
- پنل فروش لوازم جانبی

## Won't Have (در این نسخه انجام نمی‌شود)
- پشتیبانی از تعمیر لپ‌تاپ
- فروش گوشی دست دوم
- تعمیر لوازم خانگی
- نسخه چندزبانه
